# HTML

Hujjat tuzilmasi, matn, havolalar, ro'yxatlar, jadvallar, formalar, mazmunlilik, media, meta-teglar va ommaboplik - hammasi bir yerda.

HTML (HyperText Markup Language) - har qanday web-saytni qurishda ishlatiladigan belgilash tili. Bu dasturlash tili emas: teglar bilan kontentning tuzilishi va mazmunini belgilap chiqasiz, brauzer esa shu belgilarni sahifa ko'rinishiga o'giradi. Til imkoniyatlari to'liq shu yerda ko'rsatilgan, ta'riflar koddagi komment ko'rinishida.
